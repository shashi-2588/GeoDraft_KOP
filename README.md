# GeoDraft Pro – Kolhapur Edition (Web App & Android APK)

GeoDraft Pro (Kolhapur Edition) is an offline-capable groundwater survey, pump test analysis, and cadastral mapping application designed for field geoscientists and hydrogeologists.

## 📱 Features Included
1. **Dynamic Sr.No Prefix:** Automatically extracts geologist initials from Geologist Profile (e.g. *Shashikant Nimbalkar* -> `SN-001`, *Archan Bhise* -> `AB-001`).
2. **Year of Construction:** Text field support allowing `Old Well` or custom years (`2018`).
3. **Pump Discharge Options:**
   - 3 HP: `14, 15, 16, 18`
   - 5 HP: `18, 20, 22, 22.5`
   - 7.5 HP: `22, 24.75`
   - 10 HP: `24, 27`
   - 20 HP: `50`
4. **Section F Lithology ("+ Add Laterite"):** Quick insertion for:
   - Lateritic Soil
   - Weatherd Laterite
   - Laterite
   - Sandstone
5. **Cadastral 7/12 & Maps:** Built-in maps for all 12 Kolhapur talukas (Karvir, Panhala, Shahuwadi, Radhanagari, Bhudargad, Ajra, Chandgad, Gadhinglaj, Kagal, Hatkangale, Shirol, Gaganbavda).

## 🚀 How to Enable GitHub Pages
1. Go to your GitHub repository -> **Settings**.
2. In the left sidebar, click **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your live web link will be ready!
